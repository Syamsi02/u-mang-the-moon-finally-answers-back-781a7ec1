The Moon finally answers back: a small deterministic program (pure Python stdlib) that writes the Moon's one-line comeback to everyone who has ever stared up at it — four billion years of wishes, howls, and 2 a.m. promises, answered in 141 characters — to `/output/entry.txt`. The line speaks as the Moon, wry and old and a little tired of being wished upon, and lands as a comeback in one read.

## Run it

```sh
python3 -P -s main.py
```
